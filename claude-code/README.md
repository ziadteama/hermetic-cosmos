# Hermetic Cosmos

As above, so below. A Claude Code mod that brings the Hermetic Cosmos theme and Ouro, a small original forest-wanderer mascot, into Claude Code. Ouro replaces the welcome logo with a random line from the Emerald Tablet, Spinoza, Heraclitus or Ouro himself. The status line shows the moon phase and Ouro's mood, which wilts when a tool call fails. The working spinner uses nature words, `/ouro` calls him up, and the desktop app gets a night-indigo and gold color theme.
